A triage score, with visible limits.

All point weights and usage thresholds in triage-v3.0.0 are unverified heuristics. A score of 100 can have missing evidence. Grades: A 90–100 · B 75–89 · C 60–74 · D 40–59 · F 0–39. Counters are historical totals, never inferred failure rates.

Fleet summary uses the lowest asset score. Trends use dated snapshots of the same fleet + asset ID. Device-path identities can change after reconnects; confirm mapping. Reports with SYNTH-UNASSIGNED share a placeholder scope and should be assigned separate fleet labels before combining. Library full/empty status does not establish door, sensor, or complete exception health. See the package’s docs/SCORING.md for public references and the complete policy.

File picker accepts schema v3. Migrate v2 locally with tapediag migrate --from-file report-v2.json. The CLI dashboard command accepts v1, v2 and v3 reports.
